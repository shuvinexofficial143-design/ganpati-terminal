# Ganpati Terminal

VS Code / Windows terminal me uploaded Ganpati photo ko colored dots ke roop me slow-motion line-by-line render karta hai.

## Run

```bat
run.bat
```

Ya:

```bash
python -m pip install -r requirements.txt
python ganpati.py
```

Optional slow speed:

```bash
python ganpati.py 0.06
```

Chhota number = fast, bada number = slow.
